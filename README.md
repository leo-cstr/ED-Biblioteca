# Projeto Prático: Biblioteca usando BST

Este projeto implementa uma Árvore Binária de Busca (BST) em linguagem C11 para o cadastro de livros.

## Como Compilar e Executar (Linux / Windows com MinGW)
1. Abra o terminal na raiz do projeto.
2. Compile utilizando o GCC: `gcc -std=c11 src/main.c src/bst.c -I include -o sistema`
3. Execute o programa gerado: `./sistema` (Linux) ou `sistema.exe` (Windows)
